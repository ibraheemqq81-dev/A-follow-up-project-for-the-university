# RECOVERY.md — خطة الاسترجاع الآمن والطوارئ

## 1. عند حدوث خطأ فادح أو تلف في الملفات
1. لا تقم بحذف قاعدة البيانات أو مجلد المشروع.
2. استرجع الحالة السريعة عبر النسخ الاحتياطي اليدوي أو عبر مستودع GitHub (إذا كان متوفراً).
3. تحقق من إصدارات Node.js والتبعيات عبر `npm install`.

## 2. استرجاع قاعدة البيانات
- استخدم سكريبت النسخ الاحتياطي المعتمد داخل المشروع (`npm run backup`) أو انسخ ملف قاعدة البيانات SQLite بأمان.
- في حال تلف الإعدادات، أعد تشغيل السيرفر ليقوم بإنشاء القيم الافتراضية بأمان دون مسح الجداول الحالية.
