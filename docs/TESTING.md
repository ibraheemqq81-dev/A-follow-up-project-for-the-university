# TESTING.md — دليل الاختبارات والتحقق

## 1. الاختبارات البرمجية المتاحة
- **فحص الأنواع والـ Lint**: `npm run lint` (`tsc --noEmit`).
- **اختبارات التكامل والوظائف**: `npm test` (`tsx scripts/run-tests-isolated.ts`).
- **فحص صحة النظام**: `npm run healthcheck`.

## 2. خطوات التحقق اليدوي
1. تسجيل الدخول بصلاحيات مختلفة (مالك، مسؤول كلية، مسؤول قسم، تدريسي).
2. التحقق من عدم القدرة على رؤية بيانات الكليات أو الأقسام الأخرى (Scope enforcement).
3. تسجيل حضور محاضرة وتوثيقها بالكاميرا أو الختم المائي الرقمي.
4. اختبار وضع عدم الاتصال والمزامنة التلقائية عند عودة الإنترنت.
5. تجربة تثبيت التطبيق عبر زر PWA Install في الواجهة.
