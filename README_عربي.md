# نظام متابعة حضور التدريسيين — جامعة المستقبل

1. فك ملف ZIP في مجلد ثابت، وثبّت Node.js 22.5 أو أحدث؛ أو ضع النسخة المحمولة في `node-portable`.
2. شغّل `start.bat` وانتظر فتح `http://localhost:3000`؛ يحتاج الاتصال بالإنترنت عند تثبيت الحزم أول مرة.
3. في نافذة PowerShell ثانية، انتقل إلى مجلد البرنامج وشغّل `npm run admin:create` ثم أدخل كلمة مرور المدير.
4. افتح النظام وسجّل الدخول بالبريد وكلمة المرور اللذين أدخلتهما.
5. للنسخ الاحتياطي شغّل `backup.bat`؛ ولتصدير البيانات أو استعادتها استخدم `export-data.bat` و`import-data.bat`.
6. إذا لم يعمل، تأكد من Node.js 22.5 أو أحدث، ثم أغلق أي خادم آخر يستخدم المنفذ 3000 وأعد `start.bat`.
7. لا تتضمن الحزمة قاعدة بيانات أو ملف إعدادات سرياً؛ لا تحذف `data` بعد بدء الاستخدام.
8. تفاصيل الاختبارات والتطوير في `CODEX_CONTINUATION_FOR_CLAUDE.md` و`CODEX_PROGRESS.md`.
