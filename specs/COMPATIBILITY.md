# COMPATIBILITY.md — سياسة التوافق بين إصدارات الأدوات والنماذج

## 1. توافق النماذج (Model Compatibility)
- عند الانتقال بين نماذج ذكاء اصطناعي حديثة وأقدم، يجب عدم السماح للنموذج الأقدم بإعادة كتابة الملفات الكبيرة أو الهياكل دون فهم دقيق.
- الالتزام بالتعديلات الجزئية والمحددة (Incremental Edits).
- التحقق الفوري من توافق الأنواع باستخدام `tsc --noEmit`.

## 2. توافق البيئة والتبعيات (Environment & Dependencies)
- بيئة التشغيل المطلوبة: Node.js 22.5 أو أحدث.
- ممنوع تغيير إصدارات المكتبات الأساسية بدون اختبار شامل.
- الحفاظ على قواعد التخزين المؤقت والـ PWA وعدم تخزين البيانات الحساسة (`/api/auth`, `/api/users`) في الـ Service Worker Cache.
