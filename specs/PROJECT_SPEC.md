# PROJECT_SPEC.md — المواصفات الوظيفية الكاملة

## 1. نظرة عامة
نظام متابعة حضور التدريسيين والمحاضرات لجامعة المستقبل يتيح إدارة الجداول الأكاديمية، تتبع حضور التدريسيين، توثيق القاعات عبر الكاميرا والختم الرقمي المائي، إدارة الأقسام والكليات، استيراد جداول Excel، إصدار التقارير اليومية والرسمية، ودعم PWA والعمل بدون اتصال (Offline mode) مع المزامنة الآمنة.

## 2. الأدوار والصلاحيات (RBAC)
- **مالك الجامعة (OWNER)**: صلاحيات كاملة على مستوى الجامعة، إدارة المستخدمين، الصلاحيات، النسخ الاحتياطي، إعدادات الحسابات وكلمات المرور.
- **مسؤول الكلية (COLLEGE_MONITOR / COLLEGE_DEAN)**: إدارة كليته والأساتذة والأقسام والجداول والمتابعة الحية وتقارير الكلية.
- **مسؤول القسم (DEPARTMENT_MONITOR)**: إدارة جداول وشعب وأقسام القسم، تسجيل الحضور بالنيابة مع السبب، ومتابعة تدريسيي القسم.
- **التدريسي (FACULTY)**: بوابة تسجيل حضور المحاضرات الخاصة به، توثيق القاعة بالكاميرا، وطلبات تأجيل أو تعديل المحاضرات.

## 3. الميزات الأساسية
- **تسجيل الحضور والتوثيق**: التقط صورة القاعة والطلبة مع العلامة المائية الرسمية، أو استخدام التوثيق الرقمي المائي في حال تعذر الكاميرا.
- **التسجيل نيابة عن التدريسي**: إمكانية إشرافية لتسجيل الحضور مع إثبات السبب الإلزامي (نسيان، عطل فني...).
- **منع التعارضات**: فحص القاعات والأوقات والجداول لمنع تداخل المحاضرات.
- **استيراد البيانات**: مركز استيراد متكامل لجداول الأقسام والتدريسيين من ملفات Excel مع المعاينة والتحقق.
- **PWA والتجاوب**: دعم كامل لتثبيت التطبيق على الهواتف وسطح المكتب والتشغيل بوضع عدم الاتصال مع المزامنة الذكية ومقاومة التكرار.
