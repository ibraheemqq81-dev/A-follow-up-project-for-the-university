# نظام متابعة حضور التدريسيين — جامعة المستقبل
1. على الجهاز الأول شغّل `pack.bat`؛ ستجد المجلد الجاهز في `portable-package`.
2. انسخ مجلد `portable-package` كاملاً إلى الفلاشة ثم إلى مجلد بالجهاز الجديد.
3. يمكن وضع Node.js 22.5 أو أحدث في `node-portable`؛ وإلا ثبّته من https://nodejs.org/.
4. شغّل `start.bat`؛ يحتاج اتصالاً بالإنترنت لتثبيت الحزم أول مرة.
5. ينشئ التشغيل الإعدادات ومفتاح الجلسة والقاعدة تلقائياً، ويفتح `http://localhost:3000`.
6. انقل بياناتك عبر `export-data.bat` ثم انسخ الملف الناتج إلى الجهاز الجديد.
7. في الجهاز الجديد شغّل `import-data.bat` وأدخل مسار الملف واكتب «نعم» للتأكيد.
8. شغّل `backup.bat` لحفظ نسخة مؤرخة داخل `backups`.
9. إذا تعذر التشغيل، تحقق من إصدار Node واتصال الإنترنت ثم أعد `start.bat`.
