# نظام متابعة حضور التدريسيين والمحاضرات — جامعة المستقبل
## Al-Mustaqbal University Academic Attendance System

### الميزات المحدثة حديثاً (دعم تطبيق الويب المتجاوب و PWA):
1. **تطبيق ويب متجاوب بالكامل (Responsive Web App)**: واجهات مستخدم مخصصة للشاشات الكبيرة وصغيرة الحجم مع شريط تنقل سفلي خاص للهواتف الذكية (Mobile Bottom Navigation).
2. **دعم PWA الشامل والتثبيت (Progressive Web App)**:
   - ملف `manifest.webmanifest` و `manifest.json` مع أيقونات عالية الدقة بأبعاد 192x192 و 512x512 و Maskable وأيقونات Apple Touch.
   - زر تثبيت ذكي في الشريط العلوي (`PWAInstallButton`) يتيح التثبيت المباشر بنقرة واحدة على الهواتف الذكية وأجهزة سطح المكتب، مع إرشادات مخصصة لمستخدمي iOS Safari.
   - مسجل Service Worker (`public/sw.js`) يدعم التخزين المؤقت الذكي مع حماية تامة تمنع تخزين البيانات الحساسة وكلمات المرور في التخزين المؤقت.
3. **العمل بدون اتصال والمزامنة الآمنة (Offline Mode & Sync)**:
   - شريط حالة الاتصال الحقيقي (`OfflineStatusBar`).
   - إمكانية تسجيل حضور المحاضرات وتوثيقها بالكاميرا أو الختم الرقمي محلياً عند انقطاع الإنترنت، مع مزامنة تلقائية وآمنة فور عودة الاتصال مع منع تكرار السجلات (Idempotency / 409 Conflict Protection).
4. **توثيق الكاميرا والجهات**:
   - دعم كامل لالتقاط صور القاعة والطلبة من الهواتف والأجهزة اللوحية مع العلامة المائية الرسمية لجامعة المستقبل.

### التشغيل والتعليمات الأساسية:
1. على الجهاز الأول شغّل `pack.bat`؛ ستجد المجلد الجاهز في `portable-package`.
2. انسخ مجلد `portable-package` كاملاً إلى الفلاشة ثم إلى مجلد بالجهاز الجديد.
3. يمكن وضع Node.js 22.5 أو أحدث في `node-portable`؛ وإلا ثبّته من https://nodejs.org/.
4. شغّل `start.bat`؛ يحتاج اتصالاً بالإنترنت لتثبيت الحزم أول مرة.
5. ينشئ التشغيل الإعدادات ومفتاح الجلسة والقاعدة تلقائياً، ويفتح `http://localhost:3000`.
6. انقل بياناتك عبر `export-data.bat` ثم انسخ الملف الناتج إلى الجهاز الجديد.
7. في الجهاز الجديد شغّل `import-data.bat` وأدخل مسار الملف واكتب «نعم» للتأكيد.
8. شغّل `backup.bat` لحفظ نسخة مؤرخة داخل `backups`.
9. إذا تعذر التشغيل، تحقق من إصدار Node واتصال الإنترنت ثم أعد `start.bat`.
